# This is a personal learning/portfolio project.

Thank you for your attention to `Ember`.
The motivation behind it is to learn new graphics techniques and optimization.

### Do not contribute

- As this is for personal learning, I see little benefit to opening the engine for contributions.
  - Instead, it would be more interesting to see competing designs for features and to compare notes.
- Feel free to discuss the engine and design.
- As licensed, you can fork it for your own learning.

### LLM Usage

- This is a learning project - implementing anything here for the sake of implementing is pointless.
- So, do not use LLM to generate or design anything here, since it does not help in learning.
